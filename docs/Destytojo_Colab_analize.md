Kiekvienai atskirai aprašykite:

| Klausimas | Ką užrašyti pagal tikrą failą |
| --- | --- |
| Tikslas | Kokią konkrečią užduotį sprendžia užrašinė |
| X | Kokią įvestį, failą ar duomenų rinkinį naudoja |
| y | Kokią išvestį prognozuoja ar generuoja |
| Bibliotekos | Kokie importai ir jų paskirtis |
| Modelis | Pavadinimas ir ar jis mokomas, ar tik vykdoma inferencija |
| Etapai | Duomenų paruošimas, kvietimas / mokymas, vertinimas |
| Rezultatai | Kokie tikri skaičiai, grafikai ar išvestys matomi |
| Ryšys su darbu | Ką galima pritaikyti Python kodo peržiūrai |

du originalius failus galima pateikti papildomai, kad analizė būtų tiksli.
